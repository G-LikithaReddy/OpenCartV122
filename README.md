# Selenium TestNG OpenCart Automation Framework

This project is a UI automation framework built using Selenium WebDriver, Java, TestNG, and Maven.  
It automates core user workflows in the OpenCart e-commerce application.

## Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven
- Page Object Model (POM)

## Features
- Login tests
- Product search tests
- Add to cart scenarios
- Data-driven testing
- TestNG reporting
- Screenshot capture on failure

## Project Structure
- src/test/java → Test classes
- testData → Test data files
- screenshots → Failure screenshots
- pom.xml → Maven dependencies
- testng.xml → Test execution configuration

## How to Run
1. Clone the repository
2. Open in IntelliJ or Eclipse
3. Run using TestNG:
   - Right click `testng.xml`
   - Select **Run**

Or run via Maven:

mvn clean test
